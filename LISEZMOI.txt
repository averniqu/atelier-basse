Atelier de lignes de basse — application installable — version 119

Adresse : https://averniqu.github.io/atelier-basse/ (dépôt GitHub averniqu/atelier-basse).
Mise à jour : dans le dépôt, Add file › Upload files, glisser les fichiers de ce dossier
(au minimum index.html et sw.js), puis Commit changes. Sur chaque appareil, rouvrir
l'application deux fois pour qu'elle passe à la nouvelle version.
iPhone / iPad : Safari › Partager › Sur l'écran d'accueil (Ouvrir comme app web).
Android : Chrome › ⋮ › Installer l'application. Mac : Chrome › icône d'installation dans la barre d'adresse.
